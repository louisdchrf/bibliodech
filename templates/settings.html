    Lancer manuellement les traitements de données. Chaque tâche s'exécute en arrière-plan.

    Compléter les livres manquants
    Relance l'enrichissement pour les livres sans titre ou non trouvés lors du scan initial.
    Recharger toute la bibliothèque
    Ré-interroge toutes les sources pour chaque livre avec un ISBN. Peut prendre plusieurs minutes.
    Détecter les séries (heuristiques)
    Analyse les titres pour détecter des patterns "Tome N" et assigne automatiquement les séries trouvées.
    Analyser les séries (Open Library + Web)
    Interroge Open Library et DuckDuckGo pour proposer des séries sur les livres non encore assignés. Retourne des propositions à valider.
    Voir les propositions →
    Chercher les tomes manquants (toutes les séries)
    Lance une recherche web pour chaque série afin de détecter les nouvelles sorties et tomes manquants. Peut prendre plusieurs minutes selon le nombre de séries.
    Voir les manquants →
    Trouver les tomes manquants dans la bibliothèque
    Recherche dans toute la bibliothèque les livres dont le titre correspond à un tome manquant d'une série (ex : "Lady S. - Tome 4" non rattaché à la série Lady S.).
    Normaliser les auteurs
    Convertit les auteurs en format bibliographique inversé "Nom, Prénom" vers "Prénom Nom" pour tous les livres. Les institutions sont ignorées.
    Fusionner les séries en doublon
    Détecte les séries dont les noms sont quasi-identiques (casse, ponctuation, accents) et propose de les fusionner.
